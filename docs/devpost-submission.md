# Tabs Anonymous: Last Tab Standing

## Tagline

Your browser tabs formed a support group. You are the moderator.

## Inspiration

A crowded browser is a collection of unfinished intentions: a tutorial, a shopping cart, a video, and three copies of the same problem. We wanted to make sorting through that mess feel like a short comedy instead of another productivity chore.

## What it does

Tabs Anonymous turns up to twelve browser tabs into animated characters in a therapy room. A confident therapist hosts the meeting. Tabs defend their usefulness, expose duplicates, and testify about one another. You can give someone the microphone, roast a tab, or call a witness.

The final vote gives every character a destination: keep up to six in the spotlight, help them find a group, or retire them to the balcony. These are fictional decisions; real tabs stay open. The session ends with an award, a high-resolution PNG card, a text recap, and an optional silent Full HD video.

The web demo uses fictional tabs and needs no extension. The optional Chrome extension reads eligible tab titles and URLs with permission. It offers a separate native grouping preview that must be reviewed and explicitly applied.

## How we built it

React and TypeScript power a shared web and Manifest V3 extension interface. Original SVG characters have independent expressions and accessories. A deterministic reducer handles decisions, relationships, and awards, while a cancellable animation clock controls playback.

Qwen3 through local Ollama writes short replies from bounded tab metadata and recent conversation. Kokoro synthesizes speech on the same computer, with George as the therapist and distinct voices assigned automatically to the tabs. Preparing the next reply and its audio during the current line reduces pauses. No cloud API key is required. If the writer is unavailable, the game clearly falls back to contextual scripted captions.

Canvas renders the PNG and video exports locally. Browser tests cover desktop and mobile play, downloads, cancellation, recovery, and native Chromium grouping in a disposable profile.

## Challenges

The hardest part was coordinating dialogue generation, speech, animation, and user interruptions. A late reply must not replace a newer scene, and undoing a verdict must refresh what the therapist knows. We also separated fictional game decisions from real browser operations so a joke can never close a tab or silently move it.

## Accomplishments

A complete playable local experience with expressive characters, contextual dialogue, reversible verdicts, session recovery, optional approved grouping, and shareable awards. The same interface runs as a fictional web demo and as a real-tab extension.

## What we learned

Personality depends on timing and context as much as artwork. Clear fallback states, cancellable work, and explicit browser permissions are essential for a playful experience people can trust.

## What's next

A publicly hosted demo, richer emotional performances, and more varied cinematic interactions. The current local voice and writer setup requires separate model downloads; neither model is bundled in the extension.

## Built with

TypeScript, React, Vite, Motion, SVG, Canvas, Chrome Manifest V3, Kokoro, Ollama, Qwen3, Vitest, Playwright.
